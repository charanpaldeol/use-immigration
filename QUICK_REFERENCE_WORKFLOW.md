## TROUBLESHOOTING: Common Issues & Fixes

### Issue: "Content is too long/short"

**Solution**: 
- Express Entry Guide: Target 3,000-3,500 words (not 2,000, not 4,000)
- OINP Guide: Target 3,000-3,500 words
- TR-to-PR Guide: Target 2,500-3,000 words
- About Us: Target 1,500-2,000 words
- If content misses range → Agent should revise, not start over

---

### Issue: "I don't have current 2026 data"

**Solution**:
- Agent should do web search for:
  - Latest Express Entry draw data
  - OINP allocation info
  - Processing time updates
  - In-demand occupation lists
- All content should cite government sources
- Dates in content should be 2026 or current date

---

### Issue: "Niagara isn't mentioned enough"

**Solution**:
- Long guides (3,000+ words) should mention Niagara 5+ times
- Include dedicated "Niagara Advantage" section (200-300 words)
- Add Niagara-specific examples
- Compare Niagara vs. major cities (cost of living, job market, etc.)
- If agent completes guide without enough Niagara → Send back for revision

---

### Issue: "Calgary references still in content"

**Solution**:
- Agent should search all drafts for "Calgary"
- Remove/replace all Calgary mentions
- Replace with "Niagara" or relevant local reference
- Example: "We're based in Calgary..." → "We're based in Niagara..."
- Before publishing, QA step should catch any remaining Calgary refs

---

### Issue: "Content sounds like jargon/unclear"

**Solution**:
- Test readability: Flesch-Kincaid grade 8-10 (accessible but professional)
- Use plain language:
  - ❌ "Subsequent to the commencement of..." 
  - ✅ "After you apply..."
- Short paragraphs (3-4 sentences max)
- Use bullet points for 3+ items
- Define acronyms first use (Express Entry → EE)

---

### Issue: "Where do I publish this?"

**Solution**: 
Depends on your website platform:

**If WordPress**:
- Create new Post in Draft
- Paste content
- Add featured image
- Set tags/categories
- Schedule publish date
- Publish when ready

**If Wix/Squarespace**:
- Create new Page
- Add content to page blocks
- Upload images
- Set SEO metadata
- Publish

**If custom-built site**:
- Need specific instructions from your developer
- Usually: Add to content management system
- Set metadata & publish

**If no website yet**:
- Not covered in Phase 1
- Will be covered in Phase 2
- Can create content in Google Docs for now
